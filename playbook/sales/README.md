# Sales kit

- `rate-card.md` the prices and what each package includes.
- `services-agreement.md` the contract. Have a Malaysian lawyer read it once.
- `outreach.md` the message to send with a sample.
- `../../reports/` the public site at reports.artifisi.com. Its README has the deploy steps.

Prices live in this rate card only. The front door at `reports.artifisi.com` used to carry a copy of the price list next to the enquiry form; on 2026-10-27 it became a library of published reports with a general contact form, so there is one place the prices live now.

The front door still takes enquiries. Anyone who asks for a report drawn from their own data reaches the same inbox from the contact form, and the reply is made by hand.
