# reports.artifisi.com/samples/households

Unofficial sample of an interactive report: KRI's State of Households 2026 (CC BY 3.0) drawn with the same three.js engine as `tech-sovereignty/`. Built 25 Oct 2026 to show prospects what we sell. Every number is plain HTML text in `index.html`; the shapes for each number live in `views` in `scene.js`. Change both together.

`noindex` is set so it does not compete with KRI's own page in search.

This sample plays on scroll. The wages report replaced that with click to play, and that is the pattern to copy. See `instructions.md`.
