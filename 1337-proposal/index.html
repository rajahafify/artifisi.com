How it is built

Nothing on the public site to hack

Editors

Write in a hosted CMS with single sign-on, MFA, roles and an audit log.

Pipeline

Builds plain pages from reviewed, scanned code in a private repo.

Visitors

Get those pages from a CDN with a web firewall. No server code runs.

  • Pitch decks go to a separate encrypted store with a retention rule.
  • Hosted in a Malaysia or Singapore region, for data residency and PDPA questions.
  • Pages are pre-rendered, so Google and link previews read them in full.
