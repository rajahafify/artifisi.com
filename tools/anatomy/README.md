# Anatomy kit

`kit/iso-kit.mjs` is copied from https://github.com/wheresryan22/anatomy (MIT, see LICENSE), commit 1482e84.
It draws the isometric figures. `recorder/build.mjs` builds Fig 1 on /projects/dunia:

    node tools/anatomy/recorder/build.mjs

It writes src/figures/recorder.html, public/figures/recorder.js and src/styles/iso.css.
